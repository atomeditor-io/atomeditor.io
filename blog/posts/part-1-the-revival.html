The revival — Atom 1.63.1 on modern Electron

2026-09-13 · Part 1 of the chase log

GitHub archived Atom in 2022. The last release sat frozen on an Electron-era runtime that every modern OS had quietly left behind — newer systems rolled past its sign-up screens and its bundled Chromium. The editor was never dead; it was stuck.

The revival takes the final upstream codebase, Atom 1.63.1, and climbs it up the Electron ladder, rung by rung.

The chase ladder

Each rung is a full jump to a newer Electron — the renderer, the native modules (superstring, watcher, nsfw, tree-sitter), and the packaged installers all have to move together. Every rung is CI-built on the three desktop platforms and gated by a real smoke test, not just a compile.

  • Baselined on a modern Debian at Electron 11.
  • Climbed Electronics 13 → 37 across the chase-log issue, each jump its own tagged release.
  • Now shipping Atom 1.63.1 on Electron 37 — upstream Chromium, upstream Node, on the same editor.

Along the way the original's two biggest missing pieces got addressed:

  • The dead atom.io package registry is replaced by a static, GitHub-backed registry on this site — see Part 3.
  • Teletype (gone with the cloud) is succeeded by atom-ai, which bridges in-editor panels with CLI coding agents.

Downloads for Debian/Ubuntu, Fedora/RHEL, macOS and Windows land as CI artifacts under each release tag. Unsigned for now — right-click → Open on first launch.
